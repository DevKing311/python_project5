This project is a Computer-Based Test (CBT) system built with Python and MySQL, designed to replicate real online exams. 
It provides role-based access, allowing students and administrators to interact with the system securely and efficiently.
Admins can easily add, update, and delete questions, while students can take exams and view their results. The system 
automatically grades exams, calculates scores, and stores all results with timestamps in a well-organized database.
